## English

Brooke's Reading Room is an interactive collection shaped by memory, identity,
gender, belonging, and the quiet ways a book can continue to live with us after
its final page.

This is not a ranked list or a complete reading history. It is an evolving
shelf: a selection of books I return to, think beside, and carry into other
parts of my work.

### How to explore

- Move across the book spines to reveal their covers.
- Select a book to enter its own color and reading space.
- Use the list button to see the complete collection.
- Use the information button for mouse and keyboard controls.
- With a keyboard, use the left and right arrow keys to move. Press Space to
  open a book or return to the shelf.

The reading room works on desktop and mobile, although a larger screen offers
the fullest shelf experience.

### About the project

The interface treats a bookshelf as more than an index. Each spine keeps its
place in a shared composition, while every selected book opens into a quieter,
more intimate view. Colors are drawn from the individual covers so that moving
between books also changes the atmosphere of the room.

Designed and built by **Brooke / LIAO YUXIN**.

_"I am rooted, but I flow."_

## 中文

Brooke's Reading Room 是一座互动式的个人书架。这里收藏着一些持续影响我的书，它们与记忆、身份、性别、归属感，以及一本书在最后一页之后如何继续留在我们身边有关。

这不是一份排名，也不是完整的阅读记录，而是一座仍在生长的书架：这些书是我会反复回到、与之共同思考，并带入其他创作与生活经验中的作品。

### 如何浏览

- 将鼠标移到书脊上，可以展开并查看封面。
- 点击一本书，可以进入属于它的色彩与阅读空间。
- 点击列表按钮，可以浏览完整藏书。
- 点击信息按钮，可以查看鼠标与键盘操作说明。
- 使用键盘时，按左右方向键移动，按空格键打开书籍或返回书架。

阅读室同时支持桌面和移动设备，不过使用较大的屏幕可以获得更完整的书架体验。

### 关于这个项目

这个界面并不把书架仅仅视为索引。每一本书的书脊共同组成完整的画面，而被选中的书则会打开一个更安静、更私密的阅读视图。页面颜色取自各自的封面，因此在书籍之间移动时，阅读室的氛围也会随之改变。

由 **Brooke / LIAO YUXIN** 设计与制作。

_“我有根，但我流动。”_

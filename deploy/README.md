# 部署到阿里云香港服务器

让中国大陆不开 VPN 也能打开网站，并且能正常登录、读取书架和微信读书数据。
香港服务器**不需要 ICP 备案**。Vercel 和 GitHub Pages 继续保留，互不影响。

```
浏览器 ──► 你的域名            香港服务器上的 Caddy，直接提供网页
       └─► api.你的域名  ──►  Supabase（由服务器转发）
```

---

## 第一步：买服务器（需要你自己操作）

1. 登录阿里云，完成实名认证。
2. 购买 **轻量应用服务器**：
   - 地域：**中国香港**
   - 镜像：**系统镜像 → Ubuntu 24.04**（22.04 也可以）
   - 套餐：最低配置就够
3. 买好后，在服务器详情页：
   - 记下 **公网 IP**
   - 「远程连接 / 重置密码」：设置 **root 密码**
   - 「防火墙」：确认 **80** 和 **443** 端口是开放的（HTTP / HTTPS）

## 第二步：买域名并解析（需要你自己操作）

1. 在阿里云「域名」里买一个域名，比如 `.com`，并完成**域名实名认证**（几小时到一两天）。
2. 在「云解析 DNS」里给这个域名加三条 **A 记录**，记录值都是服务器的公网 IP：

   | 主机记录 | 记录类型 | 记录值 |
   |---|---|---|
   | `@`   | A | 服务器公网 IP |
   | `www` | A | 服务器公网 IP |
   | `api` | A | 服务器公网 IP |

3. 等几分钟让解析生效。

> 域名用于香港服务器，不需要备案。

## 第三步：安装并上线（在 Mac 终端里运行）

在项目文件夹 `brooke-bookshelf` 里运行（把 IP 和域名换成你的）：

```bash
deploy/setup-server.sh 服务器IP 你的域名.com
```

中途会让你输入 root 密码（可能两三次）。它会：
- 在服务器上安装 Caddy（自动申请和续期 HTTPS 证书）
- 写好网站和 Supabase 转发的配置
- 把网站文件传上去

几分钟后打开 `https://你的域名.com` 就能访问。

## 第四步：在 Supabase 里加上新域名（告诉我域名，我来改；或者你自己改）

Supabase 后台 → Authentication → URL Configuration → **Redirect URLs** 里加：

```
https://你的域名.com/**
```

这样注册确认邮件、找回密码邮件里的链接才能跳回新域名。

## 以后更新网站

改完代码后，在 Mac 上运行：

```bash
deploy/deploy.sh 服务器IP
```

只会上传网页需要的文件；`config.local.js`、`supabase/` 文件夹、文档都不会上传。

---

## 说明

- **网站怎么知道走转发**：`config.js` 会看当前打开的域名。在你自己的域名上，就通过 `api.你的域名` 连 Supabase；在 Vercel、GitHub Pages 和本地，还是直接连。
- **以前上传的书封和头像**，地址里是 `supabase.co`，在你的域名上打开时会自动改成走 `api.你的域名`。
- **所有请求都从服务器转发**，Supabase 看到的都是同一个 IP。用户少的时候没有影响。如果以后用户很多，频繁登录可能碰到 Supabase 按 IP 计算的频率限制，到时再处理。
- **登录状态**：Vercel 上和新域名上是两个不同的网站，需要各自登录一次。
